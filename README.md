
# 🚛 Controle de Cargas

Projeto para controle de cargas e viagens de caminhoneiros.

A ideia surgiu a partir de uma necessidade real: substituir o controle manual feito em caderno por uma aplicação simples para registrar e acompanhar cargas.

## Objetivo inicial

O sistema permitirá:

- Cadastrar cargas
- Registrar origem e destino
- Registrar peso e tipo da carga
- Registrar valor do frete
- Acompanhar o status da viagem
- Registrar recebimentos
- Consultar valores recebidos e pendentes
